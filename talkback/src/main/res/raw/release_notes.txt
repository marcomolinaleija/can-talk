CAN Talk 1.0.11

- El actualizador de CAN Talk ahora consulta las versiones oficiales desde la organización can-apps en GitHub (can-apps/can-talk) para que recibas las próximas actualizaciones directamente desde ese repositorio.
- Se corrige Toque directo para respetar la región táctil de los teclados que cuentan con su propio servicio de accesibilidad, evitando que la barra de navegación o las aplicaciones con toque directo la sobrescriban mientras el teclado está visible.
- Se declara el metadato keeps_keyboard_region en DirectTouchService para indicar a las aplicaciones compatibles que CAN Talk conserva la región del teclado.
